# TicHub
TicHub is a modern event ticket booking platform inspired by BookMyShow, built with a 0% commission model that lets organizers sell tickets without platform cuts. It enables seamless discovery, booking, and management of events while maximizing revenue for creators and providing a smooth, user-friendly experience for customers.
